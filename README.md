# AkaTanaka / 田中朱

面白い技術を見つけて、暮らしで使える道具や、遊べるものを作っています。

## 作っているもの

- **AlarmBulk（まとめて目覚まし）**：複数のアラームをまとめて扱うアプリ。
- **memento（Memento Mori）**：時間を週や回数で眺めるアプリ。
- **Space Colony**：開発中のゲーム。

アプリの機能紹介に加えて、制作中に気になった技術や、試して分かったことを発信していきます。

## このアカウントで扱うこと

- 個人開発アプリとゲーム
- 小さな技術実験
- 道具の使いどころと、導入前に確認したい条件

公式資料をもとにした紹介と、実際に試した結果を分けて記載します。公開していないソースコードや、まだ検証していない実績を公開済みとして紹介することはしません。
